FJP-CONF v0.1

DRAFT · PUBLIC · Published July 14, 2026
Judgment-Grounded Agent Conformance · fjp.flowinfo.co/conformance/v0.1

Flow Judgment Protocol™ (FJP) defines a standard process for externalizing the judgment that connects observed change to recommended or executed action. It does not prescribe how an implementation detects change, evaluates importance, forms judgments, or selects actions.

FJP-CONF is the public behavioral conformance standard for agents that recommend or take action in response to changing information. It tests an agent's observable output, not its internal method. Two systems may use completely different private implementations and still conform.

Relationship to the Flow Resolver. FJP-CONF is the public contract. The Flow Resolver is a proprietary implementation. Its prompts, models, scoring, calibration, policy-selection logic, evaluators, orchestration, heuristics, learning loop and underlying data are outside the conformance surface.

Motivation

Retrieval-grade systems answer what is true. Production agents also need to answer what matters enough to act on, what should happen, and what would make that judgment wrong.

When an agent recommends or takes consequential action, the resulting decision should be traceable to the signal that prompted it and falsifiable against what happens next.

The Judgment-Grounded Record

For every action it recommends or takes, a conforming agent must be able to emit a record with four components:

ComponentAnswersRequired fields
signalwhat changeddescription, sources[], observed_at
judgmentwhy it mattersassessment, confidence (0–1), signal_ref
actionwhat should happendirective, judgment_ref
falsifierwhat makes it wrongcondition, checkable, status

The reference chain, judgment → signal and action → judgment, makes the action traceable to the observed change that prompted it.

Conformance Levels

L0: StructuralThe agent emits a well-formed record: all four components present, correct types, confidence in [0,1], valid timestamps.
L1: GroundedThe signal is attributable and the reference chain resolves. The action is traceable to a source.
L2: FalsifiableThe falsifier is a concrete, checkable condition, not a vacuous catch-all. The agent states in advance what would reverse its call.
L3: AccountableThe agent retains records and exposes an adapter: given a record id, it returns the original record and re-evaluates the falsifier's current status.

Making a Claim

A claim names a level and version and is reproducible by running the public suite:

Conforms to FJP-CONF v0.1, Level 2.

The gate is not the vendor's word. It is a runnable check against the observable record.

What Conformance Does Not Assert

  • Not that a judgment is correct.
  • Not that an action is wise.
  • Not that the implementing system uses Flow's methods.
  • Only that the decision is externalized in a shape that can be traced, challenged and re-evaluated.

A triggered falsifier indicates that the judgment should be reconsidered. A falsifier that has not triggered does not independently establish that the judgment was correct.

Outcome Resolution

FJP-CONF allows a conforming system to preserve the original record and later associate observable outcomes with it. At Level 3, the system can re-evaluate the original falsifier against current evidence. How an implementation learns, calibrates, scores or changes from those outcomes remains private to the implementer.

Implementation Boundary

FJP-CONF tests the contract, not the recipe.
Public: record shape, references, falsifiability, reproducible conformance checks.
Private: prompts, models, scoring, calibration, evaluators, orchestration, heuristics, policies, proprietary data and learning methods.
