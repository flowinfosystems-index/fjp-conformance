Adding credits

Lost your key? Reset it here. Your credits stay on the account.

2. Put Abe in front of your agent

Abe is free and runs locally. It acts on or blocks the obvious cases itself and sends only escalations to Flow, so most agent actions cost nothing.

pip install abe-flow export FLOW_API_KEY=fjp_live_...

Abe setup · Also on npm and Docker.

3. Or call Flow directly

curl -X POST https://resolve.flowinfo.co/api/v1/tools/judge \ -H "Authorization: Bearer fjp_live_..." \ -H "Content-Type: application/json" \ -d '{"context":"Agent proposes a $12,000 refund. Autonomous authority: $5,000. Manager approval: absent."}'

Use the returned action and falsifier to decide whether your application proceeds, holds or escalates. Keep the request_id.

4. Report the outcome (free)

When the result is known, report it against the original request_id. outcome is CORRECT, WRONG or PARTIAL.

curl -X POST https://resolve.flowinfo.co/api/v1/outcome \ -H "Authorization: Bearer fjp_live_..." \ -H "Content-Type: application/json" \ -d '{"request_id":"<request_id from the judge response>","outcome":"CORRECT"}'
Judgment → action → outcome → resolution.
That is the loop FJP brings to production agents.
