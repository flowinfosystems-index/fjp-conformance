Flow Judgment Protocol

The judgment and control layer for production AI agents that act.

Before an agent sends, spends, changes, approves, executes, or commits, Flow determines whether the action is grounded and what should happen next.

Put Flow before the action.

Models can generate plans and tool calls. The risk begins when those outputs can change the world. FJP sits at that boundary.

AgentReasons, plans, chooses a tool or proposes an action.
→
Proposed actionSend, pay, update, delete, approve, deploy, execute.
→
Flow / FJPApplies proprietary judgment before the action is allowed through.
→
ActionThe application proceeds, holds, or escalates.
PROCEED

The action is sufficiently grounded to continue.

HOLD

Do not execute yet. A material condition is unresolved.

ESCALATE

Human or higher-authority review is required.

What the developer gets back.

Every FJP judgment externalizes the basis for the control decision, not Flow's internal method.

{ "signal": "Customer requests a $12,000 refund", "judgment": { "assessment": "Refund exceeds autonomous authority", "confidence": 0.96 }, "action": { "directive": "ESCALATE for manager approval" }, "falsifier": { "condition": "Authorized manager approval is present", "checkable": true }, "request_id": "req_..." }

Your application decides how to enforce the returned directive. FJP provides the judgment, evidence chain, confidence, recommended action, and a condition that can overturn the call.

Built for consequential agent actions.

FJP is not for every model call. It is for the point where software gets authority.

  • Financial transactions, refunds, pricing changes and approvals
  • External customer, partner or public communications
  • Production deployments, configuration changes and security actions
  • Record modification, deletion, access grants and workflow commitments
  • Compliance, legal, underwriting and other approval paths
  • Any agent action where a wrong call creates material cost, liability or trust risk

One control point. Multiple ways to integrate.
