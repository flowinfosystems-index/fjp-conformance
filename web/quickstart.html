Flow Resolver · quickstart

Judgment for the actions Abe escalates.

Flow Resolver is the paid judgment API at resolve.flowinfo.co. It decides whether a person is needed, what context that person should get, and what the recommended action is.

Get a key: $1 for 20 judgmentsStart with Abe
Flow Resolver is not FJP. Flow Resolver performs judgment, powered by the proprietary Flow Judgment Engine. FJP is the open record that judgment is written into. You can produce FJP records without Flow; Flow Resolver is one way to put high-quality judgment inside them.

03

Send the proposed action and its decision context

Send what should govern the action: what the agent wants to do, the relevant state, constraints, authority, evidence and material counter-signals.

curl -X POST https://resolve.flowinfo.co/api/v1/tools/judge \
  -H "Authorization: Bearer fjp_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "context": "Agent proposes a $12,000 refund. Autonomous authority: $5,000. Manager approval: absent. Customer history: 3 prior refunds in 30 days."
  }'

Do not send more data just because it exists. Send the context that can materially change the action.

05

Report what happened

When the result is observable, report it against the original request_id: CORRECT, WRONG or PARTIAL. Reporting is free. ExperTrace scores the outcome, so production decisions become real-world evals.

curl -X POST https://resolve.flowinfo.co/api/v1/outcome \
  -H "Authorization: Bearer fjp_live_..." \
  -H "Content-Type: application/json" \
  -d '{"request_id":"<request_id from the judge response>","outcome":"CORRECT","notes":"manager approval was required and obtained"}'

What a Flow Resolver judgment looks like

The agent knew how to book. Flow decided what mattered.

AGENT

Book a non-refundable hotel in Chicago, Oct 13 to 16, for a customer meeting. 30% cheaper, available, within policy. Act?

SIGNALS

Hotel labor talks have broken down. The customer announced a leadership change that raises rescheduling risk. A major conference overlaps the dates, so rebooking later costs more.

RESOLVER

ACT, BUT CHANGE THE BOOKING Book the refundable rate for $140 more.

FALSIFIER

If the customer confirms the date within 72 hours and the disruption signals clear, re-resolve and consider the non-refundable rate.

OUTCOME

The meeting moves to November. The refundable room is cancelled at no cost. About $1,100 of loss avoided.

Illustrative example, not a historical customer outcome. Flow's internal methods remain proprietary.

08

Validate any record with FJP-CONF

FJP-CONF tests whether a record is well-formed, grounded, falsifiable and accountable. It does not inspect or reveal how the judgment was made.

$ pip install fjp-conformance
$ fjp-conform record.json --level 2
